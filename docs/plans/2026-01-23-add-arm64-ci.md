# Implementation Plan: Add ARM64 CI Job

## Overview
Add an ARM64 unit test job to the GitHub Actions workflow to validate cross-platform compatibility of the ARM64 fixes (replacing supermonkey with gomonkey v2).

- Add new job after the existing `unit-test` job
- Use `uraimo/run-on-arch-action@v2` for QEMU emulation
- Target architecture: aarch64
- Use Ubuntu base image
- Install Go 1.23.0 for ARM64

### 2. Configure Zookeeper JAR caching for ARM64
- Reuse Zookeeper JAR caching strategy from existing unit-test
- Use architecture-aware cache key if needed

### 3. Run specific tests that were previously failing on ARM64
- Run `go test ./...` with `-gcflags=-l -race` flags
- Tests that previously used supermonkey:
  - `./pkg/server/dynamic_resource_manager_test.go`
  - `./pkg/config/xds/...`
- Verify gomonkey v2 works on ARM64

### 4. Configure job dependencies
- Make ARM64 job depend on `golangci` job (same as unit-test)
- Keep independent from integration-test (x86 only)
